# Lock screen, idle, and night light

## Locking the screen

Choose `Haku Menu > General > Quit > Lock`, or use the lock option in the power menu. Unlock with the password for the current account.

## Automatic locking when idle

HakuSpace can turn off the display, lock the screen, and suspend after periods of inactivity. The default timeouts can be changed in `~/hakucfg/config/hypridle.conf`.

## Night light

Press `SUPER + L` to toggle a warmer display color at night. This reduces blue light; it does not replace the physical brightness control of the display.

## Temporarily preventing idle actions

When watching a video or presenting, use the player's idle-inhibit mode if available. Turn it off afterward so the system can lock normally again.
