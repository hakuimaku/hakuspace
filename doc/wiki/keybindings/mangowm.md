# MangoWM Keybindings

MangoWM uses `SUPER` as the main modifier. These shortcuts use the default HakuSpace MangoWM configuration.

## Applications and HakuSpace features

| Key | Action |
|---|---|
| `SUPER + Q` | Open Kitty |
| `SUPER + E` | Open Thunar |
| `SUPER + B` | Open Firefox |
| `SUPER + R` | Open the application launcher |
| `SUPER + N` | Open the notification center |
| `SUPER + /` | Open the emoji picker |
| `SUPER + TAB` | Open Haku Menu |
| `SUPER + V` | Open clipboard history |
| `SUPER + SHIFT + V` | Clear clipboard history |
| `SUPER + F11` | Start or stop screen recording |
| `SUPER + Y` | Choose a wallpaper |
| `SUPER + SHIFT + Y` | Choose a video wallpaper |
| `SUPER + P` | Capture a screen region |
| `SUPER + SHIFT + P` | Capture the full screen |
| `SUPER + T` | Toggle Cava Underbar |
| `SUPER + SHIFT + W` | Cycle the Waybar layout |
| `SUPER + W` | Toggle Dockbar |
| `SUPER + L` | Toggle night light |

## Window management

| Key | Action |
|---|---|
| `SUPER + C` | Close the focused window |
| `SUPER + Z` | Toggle floating mode |
| `SUPER + F` | Toggle maximized mode |
| `SUPER + SHIFT + F` | Toggle fullscreen mode |
| `ALT + SHIFT + F` | Toggle fake fullscreen mode |
| `ALT + TAB` | Toggle overview |
| `SUPER + X` | Toggle overlay mode |
| `SUPER + I` | Minimize the focused window |
| `SUPER + Grave` | Toggle the scratchpad |
| `SUPER + SHIFT + I` | Restore a minimized window |
| `SUPER + A` / `SUPER + Left` | Focus the window to the left |
| `SUPER + S` / `SUPER + Right` | Focus the window to the right |
| `SUPER + Up` | Focus the window above |
| `SUPER + Down` | Focus the window below |
| `SUPER + D` | Switch the scroller proportion preset |

Use `SUPER + 1` through `SUPER + 9` to switch views. Use `SUPER + SHIFT + 1` through `SUPER + SHIFT + 9` to tag the focused window for a view.

Use `SUPER + left mouse button` to move a window and `SUPER + right mouse button` to resize it.

## Other controls

- `SUPER + ALT + R`: reload MangoWM configuration.
- `SUPER + SHIFT + E`: quit MangoWM.
- `SUPER + SHIFT + Arrow`: move or exchange windows between directions.
- `SUPER + SHIFT + Arrow` with a monitor direction: focus another monitor.
- `SUPER + ALT + Arrow`: move the focused window to another monitor.
- Hardware volume and brightness keys work without holding `SUPER`.

## Customization

User changes should be made in `~/hakucfg/wm/mango-custom.conf`. Reload MangoWM with `SUPER + ALT + R` after changing the configuration.
