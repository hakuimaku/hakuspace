# Labwc Keybindings

Labwc uses `SUPER` as the window modifier. These shortcuts use the default HakuSpace Labwc configuration.

## Applications and HakuSpace features

| Key | Action |
|---|---|
| `SUPER + Q` | Open Kitty |
| `SUPER + E` | Open Thunar |
| `SUPER + B` | Open Firefox |
| `SUPER + R` | Open the application launcher |
| `SUPER + N` | Open the notification center |
| `SUPER + /` | Open the emoji picker |
| `SUPER + TAB` | Open Haku Menu |
| `SUPER + V` | Open clipboard history |
| `SUPER + SHIFT + V` | Clear clipboard history |
| `SUPER + F11` | Start or stop screen recording |
| `SUPER + Y` | Choose a wallpaper |
| `SUPER + SHIFT + Y` | Choose a video wallpaper |
| `SUPER + P` | Capture a screen region |
| `SUPER + SHIFT + P` | Capture the full screen |
| `SUPER + T` | Toggle Cava Underbar |
| `SUPER + SHIFT + W` | Cycle the Waybar layout |
| `SUPER + W` | Toggle Dockbar |
| `SUPER + L` | Toggle night light |

## Menus

| Key | Action |
|---|---|
| `SUPER + Space` | Open the root menu |
| `SUPER + Grave` | Open the client menu at the pointer |
| `Alt + Grave` | Open the combined client menu |

## Window management

| Key | Action |
|---|---|
| `SUPER + C` | Close the focused window |
| `SUPER + A` | Toggle maximize |
| `SUPER + S` | Minimize the focused window |
| `SUPER + D` | Show or hide the desktop |
| `SUPER + F` | Toggle fullscreen mode |
| `SUPER + X` | Start interactive resizing |
| `SUPER + Z` | Shrink the focused window |
| `SUPER + SHIFT + Z` | Expand the focused window |
| `Alt + Tab` | Focus the next window |
| `Alt + SHIFT + Tab` | Focus the previous window |
| `SUPER + Return` | Open a terminal using the system default |
| `SUPER + Arrow` | Snap the window to a screen edge |

Use `SUPER + 1` through `SUPER + 9` to switch desktops.

Use `Alt + W/A/S/D` to resize the focused window in a direction. Use `Alt + SHIFT + W/A/S/D` to shrink it in that direction.

## Customization

The active Labwc keybindings are stored in `~/.config/labwc/rc.xml`. Unlike the other supported window managers, HakuSpace does not currently provide a separate `labwc-custom.conf` template.
