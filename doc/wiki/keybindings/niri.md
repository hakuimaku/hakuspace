# Niri Keybindings

Niri uses `Mod` as the main modifier. It normally refers to the Windows key.

## Applications and HakuSpace features

| Key | Action |
|---|---|
| `Mod + Q` | Open Kitty |
| `Mod + E` | Open Thunar |
| `Mod + B` | Open Firefox |
| `Mod + R` | Open the application launcher |
| `Mod + N` | Open the notification center |
| `Mod + Slash` | Open the emoji picker |
| `Mod + Tab` | Open Haku Menu |
| `Mod + V` | Open clipboard history |
| `Mod + SHIFT + V` | Clear clipboard history |
| `Mod + F11` | Start or stop screen recording |
| `Mod + Y` | Choose a wallpaper |
| `Mod + SHIFT + Y` | Choose a video wallpaper |
| `Mod + P` | Capture a screen region |
| `Mod + SHIFT + P` | Capture the full screen |
| `Mod + ALT + P` | Capture the focused window |
| `Mod + T` | Center the focused column |
| `Mod + SHIFT + W` | Cycle the Waybar layout |
| `Mod + W` | Toggle Dockbar |
| `Mod + L` | Toggle night light |

## Built-in screenshots

| Key | Action |
|---|---|
| `Print` | Capture the current view |
| `Ctrl + Print` | Capture the current screen |
| `Alt + Print` | Capture the focused window |

## Window management

| Key | Action |
|---|---|
| `Mod + C` | Close the focused window |
| `Mod + Z` | Toggle floating mode |
| `Mod + F` | Maximize the focused column |
| `Mod + SHIFT + F` | Toggle fullscreen mode |
| `Mod + Grave` | Toggle overview |
| `Mod + A` / `Mod + Left` | Focus the column to the left |
| `Mod + S` / `Mod + Right` | Focus the column to the right |
| `Mod + Up` | Focus the window above |
| `Mod + Down` | Focus the window below |
| `Mod + SHIFT + A` / `Mod + SHIFT + Left` | Move the column left |
| `Mod + SHIFT + S` / `Mod + SHIFT + Right` | Move the column right |
| `Mod + Minus` / `Mod + Equal` | Decrease or increase column width |
| `Mod + SHIFT + Minus` / `Mod + SHIFT + Equal` | Decrease or increase window height |
| `Mod + X` | Switch focus between floating and tiling windows |
| `Mod + SHIFT + X` | Toggle tabbed column display |

Use `Mod + 1` through `Mod + 9` to switch workspaces. Use `Mod + Ctrl + 1` through `Mod + Ctrl + 9` to move the focused column to a workspace.

## Customization

User changes should be made in `~/hakucfg/wm/niri-custom.kdl`. The generated keybinding file should not be edited directly.
