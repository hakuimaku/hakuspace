Looking for my dotfiles configuration here!

- home/: Simulated home directory with all configuration files (.config, .local/share, etc.).
    - .config/: Contains all configuration files.
    - .local/share/hakuspace/: Contains organized HakuSpace scripts.
    - .local/bin/: Runtime symlinks are created here by the installer.
    - hakucfg/: Contains hakuspace's control-center.
- packages/: Contains package lists that will be installed (pkg-core, pkg-service, etc.).
