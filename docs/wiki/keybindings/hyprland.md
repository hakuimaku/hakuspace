# Hyprland Keybindings

`SUPER` is the Windows key. These shortcuts use the default HakuSpace Hyprland configuration.

## Applications and HakuSpace features

| Key | Action |
|---|---|
| `SUPER + Q` | Open Kitty |
| `SUPER + E` | Open Thunar |
| `SUPER + B` | Open Firefox |
| `SUPER + R` | Open the application launcher |
| `SUPER + N` | Open the notification center |
| `SUPER + /` | Open the emoji picker |
| `SUPER + TAB` | Open Haku Menu |
| `SUPER + V` | Open clipboard history |
| `SUPER + SHIFT + V` | Clear clipboard history |
| `SUPER + F11` | Start or stop screen recording |
| `SUPER + Y` | Choose a wallpaper |
| `SUPER + SHIFT + Y` | Choose a video wallpaper |
| `SUPER + P` | Capture a screen region |
| `SUPER + SHIFT + P` | Capture the full screen |
| `SUPER + T` | Toggle Cava Underbar |
| `SUPER + SHIFT + W` | Cycle the Waybar layout |
| `SUPER + W` | Toggle Dockbar |
| `SUPER + L` | Toggle night light |
| `SUPER + K` | Lock the screen |

## Window management

| Key | Action |
|---|---|
| `SUPER + C` | Close the focused window |
| `SUPER + Z` | Toggle floating mode |
| `SUPER + F` | Toggle maximized mode |
| `SUPER + SHIFT + F` | Toggle fullscreen mode |
| `SUPER + A` / `SUPER + Left` | Focus the window to the left |
| `SUPER + S` / `SUPER + Right` | Focus the window to the right |
| `SUPER + Up` | Focus the window above |
| `SUPER + Down` | Focus the window below |
| `SUPER + M` | Minimize or restore the focused window |
| `SUPER + X` | Cycle the workspace layout |
| `SUPER + Grave` | Toggle the special workspace |
| `SUPER + F1` | Toggle performance mode |
| `SUPER + F2` | Toggle minimal decoration mode |

Use `SUPER + 0` through `SUPER + 9` to switch workspaces. Use `SUPER + SHIFT + 0` through `SUPER + SHIFT + 9` to move the focused window to a workspace.

Use `SUPER + left mouse button` to move a window and `SUPER + right mouse button` to resize it.

## Media and hardware keys

The volume, microphone mute, display brightness, and media playback keys work without holding `SUPER`.

## Customization

User changes should be made in `~/hakucfg/wm/hyprland-custom.lua`. The generated keybinding file should not be edited directly.
