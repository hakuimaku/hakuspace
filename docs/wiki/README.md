# HakuSpace Wiki

This wiki explains how to use the features included in HakuSpace. It is written for daily users and does not describe the implementation or source code.

## Quick Start

- Open the main menu with `SUPER + TAB`.
- Open the application launcher with `SUPER + R`.
- Open the notification center with `SUPER + N`.
- Open the terminal with `SUPER + Q`.
