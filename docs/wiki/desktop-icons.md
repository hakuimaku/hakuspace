# Desktop Icons

Desktop Icons is an experimental feature that displays items from `~/Desktop` directly on the desktop.

## Toggling the feature

Go to `Haku Menu > Theme > Show Desktop Icons`. You may need to select the item again to reload the list after enabling it.

## Using Desktop Icons

Add a file or folder to `~/Desktop`, then reload Desktop Icons from Haku Menu. Double-click an item to open it with the default application.

If an icon is misplaced or does not update, toggle the feature off and on again. This is still experimental, so some behavior may be unstable.
