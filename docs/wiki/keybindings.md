# Keybindings

`SUPER` is the Windows key. On Niri, the equivalent name is `Mod`.

## Common shortcuts

| Key | Action |
|---|---|
| `SUPER + Q` | Open Kitty |
| `SUPER + R` | Open the application launcher |
| `SUPER + TAB` | Open Haku Menu |
| `SUPER + N` | Open the notification center |
| `SUPER + C` | Close the focused window |
| `SUPER + W` | Toggle Dockbar |
| `SUPER + P` | Capture a screen region |
| `SUPER + SHIFT + P` | Capture the full screen |
| `SUPER + V` | Open clipboard history |
| `SUPER + SHIFT + V` | Clear clipboard history |
| `SUPER + F11` | Start or stop screen recording |
| `SUPER + Y` | Choose a wallpaper |
| `SUPER + SHIFT + Y` | Choose a video wallpaper |
| `SUPER + SHIFT + W` | Cycle the Waybar layout |
| `SUPER + T` | Toggle Cava Underbar |
| `SUPER + L` | Toggle night light |
