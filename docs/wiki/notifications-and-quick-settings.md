# Notifications and quick settings

## Opening the notification center

Press `SUPER + N` to open SwayNC. Here you can review notifications and use the quick-setting buttons.

## Quick-setting buttons

The `buttons-grid` in SwayNC currently provides these toggle buttons:

| Button | Action |
|---|---|
| Wi-Fi | Turn the Wi-Fi radio on or off. |
| Bluetooth | Turn Bluetooth power on or off. |
| Night light | Toggle the HakuSpace night-light script. |
| Audio mute | Mute or unmute the default audio output. |
| Idle inhibit | Prevent or allow idle actions such as automatic locking while active. |
| Cava Underbar | Start or stop the standalone Cava visualizer layer. |
| Random wallpaper | Enable or disable automatic wallpaper changes. |
| Dockbar | Show or hide Dockbar. |

The `Volume` and `Backlight` widgets are separate controls: use them to adjust output volume and display brightness rather than toggle them.

You can also open `Audio Control` in `Haku Menu > Setting` to manage output devices, input devices, and volume in more detail.

## Power and performance menus

The SwayNC menubar includes:

- a power menu with `Reboot`, `Lock`, `Exit`, and `Shut down`;
- a power-profile menu with `Performance`, `Balanced`, and `Power-saver`.

If Wi-Fi or Bluetooth does not respond, check the related system service before reopening the notification center.
