## VERIFY conclusion table (to be filled by the agent later)

| Item | Status / Finding |
|---|---|
| Mango event format | `mmsg watch all-tags` outputs one JSON object per line containing `all_tags` with `monitor`, `index`, `is_active`, `is_urgent`, `client_count`. Verified. |
| Niri cross-output activation | Verified. `niri msg action focus-monitor <output>` followed by `niri msg action focus-workspace <idx>` works. `niri msg -j event-stream` correctly emits `WorkspacesChanged` and `WindowsChanged`. |
| Labwc ext-workspace support | **Crashes Quickshell.** `Quickshell.WindowManager.windowsets` causes a fatal C++ `std::bad_function_call` crash on Labwc with Quickshell 0.3.1. Labwc is set to `supported = false` (NullBackend). |
| Hyprland Lua syntax | Verified (ws.activate works) |
